# Wallet

Personal finance app (accounts, cards, transactions, credits, loans) backed by Supabase.

| Folder | App |
|---|---|
| [`flutter/`](flutter) | Original Flutter app (Android, iOS, web, desktop). See [flutter/readme.md](flutter/readme.md). |
| [`swift/`](swift) | Native SwiftUI port for iOS 26 with the Liquid Glass design. See [swift/README.md](swift/README.md). |

Both apps use the same Supabase project and schema (source of truth:
[danny270793/supabase](https://github.com/danny270793/supabase)).
